# Introduction
This is just a slop python script bundled into applications for personal use, at least it works. It collects zalo groups links from Google snippets, only from Facebook post. The scraper uses pyautogui and tesseract ocr to detect and navigate around.
# Usage
- Installed tesseract ocr, with additional vietnamese language package
- Open scraper, input your keyword and number of links
- Switch to Chrome, just let it do its job
- in case of getting Captcha, solve it and click Continue, switch back to Chrome
# Linux requirements
numpy, pillow, pyautogui, pyperclip, pytesseract, pytweening, PyScreeze, PyMsgBox, PyGetWindow, PyRect, MouseInfo
